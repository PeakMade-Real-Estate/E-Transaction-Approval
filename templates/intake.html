Request Type Guide
  • Wire: Same-day if released before bank cutoff.
  • ACH: ~2-day if released before bank cutoff.
  • ACH Pull: Receiving bank initiates. Use only if ACH/Wire unavailable at originating bank.
  • Intra Bank: Internal transfers. SD True Ups: accountants may move directly.
  • EFT: Canada-specific equivalent of ACH.
